# 🎮 Jogo da Velha

Meu primeiro projeto web — um Jogo da Velha construído com HTML, CSS e JavaScript puro, sem dependências externas.

🔗 **Acesse online:** [https://thayferraz-dev.github.io/jogo-da-velha](https://thayferraz-dev.github.io/jogo-da-velha)

---

## ✨ Funcionalidades

- **Modo 2 Jogadores (PvP)** — dois jogadores se alternam no mesmo computador
- **Modo vs CPU** — jogue contra uma inteligência artificial que utiliza o algoritmo Minimax, tornando a CPU imbatível
- **Placar persistente** — o placar de X, O e empates é mantido entre as partidas
- **Modal de resultado** — exibe o vencedor ou empate ao fim de cada partida
- **Visual moderno** — tema escuro com animações e design responsivo

---

## 🛠️ Tecnologias utilizadas

| Tecnologia | Uso |
|---|---|

| CSS3 | Estilização, animações e responsividade |
| JavaScript (ES6+) | Lógica do jogo e algoritmo Minimax |

## 🚀 Como executar localmente

Não é necessário instalar nada. Basta:

1. Clonar o repositório:
   ```bash
   git clone https://github.com/thayferraz-dev/jogo-da-velha.git
   ```
2. Abrir o arquivo `index.html` diretamente no navegador.

---

## 🤖 Sobre a Inteligência Artificial

A CPU utiliza o algoritmo **Minimax**, que analisa todas as jogadas possíveis e sempre escolhe a melhor opção. Isso torna a CPU **imbatível** — o melhor resultado possível contra ela é o empate.
